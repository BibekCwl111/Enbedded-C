# Embedded C & Arduino Projects

This repository contains my Embedded C and Arduino practice projects developed during my learning journey.

## Projects Included

### 1. 4-bit Binary LED
- Displays binary numbers using 4 LEDs
- Demonstrates digital output control

### 2. RGB LED Color and Delay Change using Interrupts
- Changes LED color using button interrupts
- Demonstrates interrupt handling in Arduino

### 3. Traffic Light LEDs
- Simulates traffic light sequence
- Demonstrates timing and sequencing logic

### 4. Temperature LED Bargraph
- Displays temperature level using LEDs
- Demonstrates analog input and sensor reading
